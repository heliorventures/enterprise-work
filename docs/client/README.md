# Client walkthrough

Open **`index.html`** in a browser (double-click the file).

To send it to the client:

1. Zip the whole `docs/client` folder (HTML + `screenshots`).
2. Or open `index.html` and use **Print → Save as PDF**.

Do not send `scripts/` if you want a smaller pack; the walkthrough only needs `index.html` and `screenshots/`.
